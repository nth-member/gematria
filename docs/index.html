Gematria and ASCII

The two name-value programs in the browser. gematria_names.py sums the anglicized Hebrew gematria of the letters (A=1 … I=9, J=10 … R=90, S=100 … Z=800), ignoring case, spaces and punctuation. ascii_name_sum.py sums the 7-bit ASCII code of every character, spaces, punctuation and case included.
